# 🧩 Sudoku Game (Python + Tkinter)

A lightweight Sudoku game built with Python and Tkinter. Features include puzzle generation, hint system, autosave/load, validation modes, and a timer — all wrapped in a clean UI.

---

## 🚀 Quick Start

### Requirements
- Python 3.8+
- Tkinter (included with standard Python distributions)

### Installation
```bash
git clone https://github.com/your-username/sudoku-python.git
cd sudoku-python

# Optional: create virtual environment
python -m venv .venv
source .venv/bin/activate        # macOS/Linux
.\.venv\Scripts\activate         # Windows

# No external dependencies required for runtime
```

### Run the game
```
python sudoku_game.py
py sudoku_game.py               # Windows
```

---

## 🕹️ Features

- ✅ Puzzle generator with difficulty levels: Easy, Medium, Hard
- 💡 Hint system with limited hints per game
- 🔍 Two validation modes:
  - Highlight incorrect input
  - Auto-correct invalid entries
- 🕒 Timer with autosave support
- 💾 Autosave/load system with resume prompt
- 🧭 Menu navigation and difficulty selector
- 🎉 Victory screen when puzzle is solved
